# Saas Hotel administracion interna
proyecto de aplicación web de un hotel Saas, para administrar de manera interna.

## Instalación de dependencias

Ejecuta el siguiente comando:

```bash
npm install ubigeo-fns
```
Este proyecto integra la librería `ubigeo-fns` para facilitar la gestión del ubigeo peruano, permitiendo obtener y manejar departamentos, provincias y distritos de forma eficiente en formularios dinámicos.
### Funcionalidad

- Consulta de departamentos, provincias y distritos del Perú usando `ubigeo-fns`
